# 视觉契约与提示词写法

## 一、三类镜

全片画面只有三种，每条套路按需要选一种。

### 1. 复刻镜（用得最多）

**照参数拍出那个味。** 观众看到的是"成品"——一段真的像日剧／真的像王家卫的画面。

**这里的"像"要更狠一点**：不是"有点像"，是**像到能一秒认出**。因为笑点来自"我认得这个东西"——认出得越快，后面那句吐槽落地越响。

用途：证明这套参数有效，同时让观众先认出对象。
判据：单独截一帧出来，能被认出是哪个风格吗？不能就说明参数没拆对，或者复刻得不够狠。

#### ★ 复刻镜还要承接口播的笑点

复刻镜不能只"演示参数"。**口播里最荒诞的那一句，画面必须拍出来。**

口播的幽默来自**列举与叠加**（"男主跑，女主跑，警察跑，坏蛋也跑"）。画面要用同一手法回应：**把口播列举的东西全部塞进同一画面**。

- ✗ 口播说"所有人一起跑"，画面只拍男主一个人跑——**画面比口播弱，笑点落地就哑了。**
- ✓ 同一画面里，西装男、女主、穿制服的警察、拎着赃物的坏人，四个人朝同一方向跑，表情都很认真。**荒诞在"警察和坏蛋一起跑"。**

**判据**：把这句口播念出来，再看这一镜——**画面里有没有它说的那个荒诞？** 没有，这一镜就是白拍的。

**画面可以比口播多给一笔。** 口播说"坚决不搭车"，画面就给一辆亮着"空车"灯的出租车从他们身边驶过，**四个人没有一个看它**。这一笔口播里没有，但它是同一件事的画面化，笑点会加倍。

### 2. 演示镜

**展示参数本身。** 把机位、光位、调度拍进画面——摄影机架在哪、灯从哪个方向打、前景遮挡物放在哪。

用途：让观众看见"怎么做到的"，而不只是"做出来什么样"。**这是落差的一半**——观众发现这么荒唐的东西居然真有操作规程。

判据：摄影指导看完知道器材该摆哪吗？

演示镜通常是**过肩或侧拍的"拍摄现场"视角**，画面里同时有被摄体和摄影机／灯具的一角。

### 3. 对比镜（★ 全片最强的一招）

**同一个镜头拍两遍**：一遍有这个参数，一遍没有，紧挨着放。

例："运镜 45° 跟拍"这条——
- 第一遍：正面平拍，人跑过去。**没有那个味。**
- 第二遍：侧前方 45° 跟拍，前景有栏杆掠过。**有了。**

**差别本身就是笑点。** 观众亲眼看见"加这一个参数就变了"，比任何形容词都有效——而且他会记住。

**硬要求**：两遍必须**同机位时长、同动作、同剪辑点**，只有那一个参数不同。变量多了观众就看不出是哪个参数在起作用，笑点也就散了。

**全片不超过 3 组**，只给最不可替代的那几条参数上。

## 二、全片结构怎么排

| 区间 | 内容 |
|---|---|
| 开场 | 一段复刻镜，先把"那个味"亮出来——观众先认出对象，才愿意听你拆 |
| 中段 | 每条套路：演示镜 → 复刻镜 →（关键参数加）对比镜 |
| 收尾 | 回到一段完整的复刻镜，全部参数同时在场，形成"原来如此"的回收 |

**关键参数的判断**：哪几条是该风格最不可替代的？只给它们上对比镜。

## 三、生视频提示词怎么写

**每条参数一段**，每段 5–15 秒。七段式，职责固定：

| 段 | 职责 |
|---|---|
| 【1.全局设定】 | 第一句锁死实拍质感，再写被复刻风格的质感锚点、实体道具、光影、镜头痕迹 |
| 【2.素材绑定】 | 每张图只干一件事：`@图片N 只定义 X，不得继承 Y` |
| 【3.画面契约】 | 本段要验的**参数串**＋主体特征串＋同框上限 |
| 【4.执行契约】 | 速度、剪点、机位、运镜、句法主动权、音频；对比镜加单一变量契约，演示镜加机位可见契约 |
| 【5.场景】 | 地点＋唯一光源＋空场状态 |
| 【6.分段计划】 | 段是叙事单位不是镜头单位；每镜写动作因果链，`末：`给可承接终态 |
| 【7.负向约束】 | 编号列"不要……"，最多 5 条 |

### 两条本类型特有契约

**单一变量契约**（对比镜必写）：

> 对比契约：本段两镜必须同机位时长、同动作起止、同剪辑点，唯一变量是 [参数]。除该变量外，两镜的景别、光位、表演、服化道完全一致。

**机位可见契约**（演示镜必写）：

> 演示契约：画面内必须能看到 [摄影机机身一角 / 灯具边缘 / 前景遮挡物的位置]，让观众看清该参数是怎么摆出来的；被摄体的表演保持中性，不抢焦点。

## 四、后期叠加（不进提示词）

- **参数字幕卡**：技术项标签（运镜／光位／表演／剪辑／美术／声音）＋数值，如「45° · 35mm · 2–3m」「3200K · 左后 45°」
- **对比镜的分屏标识**：「无」「有」
- **口播字幕**
- **风格名与代表作标注**

全部在剪辑阶段叠加，**不交给视频模型**，否则必出糊字与错字。

**参数卡是这支片的门面**——观众截图保存的就是它。排版要清楚，字号要大，每张停留不少于 2 秒。
