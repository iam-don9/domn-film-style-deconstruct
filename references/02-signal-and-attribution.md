# 取样与归因

这是本技能的核心步骤。**拆得对不对，全看归因。**

---

## 一、三类信号源（按效率排序）

> **★ 先调研，不许凭印象。**
> 凭印象列出来的"某某风格套路"，十有八九是**通用影视手艺**——镜头怎么摆、光怎么打、剪辑怎么切。观众吐槽的从来不是这些。
> 做法：查盘点文、吐槽贴、梗百科、评论区，**至少 3 个独立来源**，只记共同提到的条目。
> 记三样：**条目名称、具体描述、被吐槽的原话**。第三样最重要，它往往能直接变成文案句子。

### 1. 被吐槽／被模仿的点（效率最高）

群众的眼睛已经替你做了一轮显著性筛选。先从这个开始。

日剧：平地摔、日剧跑、日剧"诶"、突然的大声台词、便利店与天台
韩剧：财阀、车祸、失忆、绝症、雨
王家卫：抽帧、慢门、霓虹、画外音独白、狭窄走廊

### 2. 代表作品里反复出现的项

选 3 部代表作，各看一遍，记下重复出现的东西：构图习惯、光位、剪辑节奏、配色。

**重复 3 次以上才记。** 一次是偶然。

### 3. 行业术语与制作规范

该类型内部的行话往往直接指向技术规范。"日剧跑"在日本业界有对应的调度说法；"一镜到底"是明确的运镜约束。查一查，比自己归纳准。

### ★ 只用第 1 类是错的

第 1 类效率最高，但它选出的是**显著性最高**的，不是**最本质**的。

**被吐槽的点往往是本质的"例外"**——因为例外才显眼、才反复被看到、才值得被吐槽。本质通常是安静的，没人吐槽它。

日剧就是标准案例：被吐槽的是日剧跑、平地摔、"诶"；而本质是**克制、不说破、不给宣泄**——没人吐槽"日剧太克制了"，因为克制不显眼。

**所以三类都要取，并且做完取样后跑一次本质检验**（见 `01-essence-and-workflow.md` 步骤 2 收尾）。

### ★ 更要命的一种错：把通用手艺当成风格特征

比"拿到例外"更常见的翻车，是**把影视常识当成风格特征**。

自测只有一句话：

> **把风格名换掉，这条特征还成立吗？** 成立 = 它不是这个风格的。

失败案例（都出自我自己的一次拆解）：

| 特征 | 换了风格还成立吗 | 处置 |
|---|---|---|
| 边走边说 | 成立。美剧也这么拍 | **剔除** |
| 怼脸特写＋眼泪不掉 | 成立。韩剧更典型 | **剔除** |
| 季节空镜 | 成立。任何剧都用 | **剔除** |
| 慢镜头＋主题曲 | 成立。任何剧都有情绪高点 | **剔除** |
| 偷听 | 成立。通用桥段 | **剔除或降权** |
| **日剧跑** | **不成立**。"日剧跑"换掉日剧就不存在 | 保留 |
| **皮鞋特写＋户外也保留硬底回声** | **不成立**。换了风格没这条规矩 | 保留 |
| **天台＋两罐同款饮料** | **不成立**。换了风格不成组合 | 保留 |

**判据**：清单里至少**一半以上**是"换了风格就不成立"的。低于一半，说明你拆的是"电视剧怎么拍"，不是"这个风格怎么拍"。

**改写优于剔除。** "边走边说"可以改写成"**沿河堤并排走**"——河堤是日剧专属场景，加上就成立了。"偷听"可以改写成"**听者被门框切掉一半，且必给听者反应不给说话人**"——这个具体处理才是日剧的。

## 二、归因七项

每条特征必须归到**其中一项**。镜语六项 ＋ 叙事一项：

| 技术项 | 参数维度 |
|---|---|
| **运镜** | 机位角度、焦距、运动方式（跟／推／拉／固定／手持）、与被摄体距离、是否过肩、轴线 |
| **光位** | 方向、高度、色温、硬／软、照到哪个面、反差比、背景光如何处理 |
| **表演** | 动作顺序、节奏（延迟几拍）、呼吸与发声、视线方向、表情幅度 |
| **剪辑** | 单镜时长、切点选在哪个动作上、镜头顺序、转场方式 |
| **美术** | 色彩方案、服装造型规范、场景陈设、材质、道具 |
| **声音** | 环境声压、人声／音效比重、配乐进入点、留白、混响干湿 |
| **叙事** | 结构节点（第几集／第几幕）、单元功能、代价与后果、开放还是闭合 |

**叙事项专门收剧情套路。** 剧情套路归不到镜语里去，但它同样是可执行的技术——只是参数是结构参数而不是拍摄参数。

例：「大结局必在机场或车站追人」→ 叙事项，参数＝**结局节点必须给一个"物理上赶得上、时间上赶不上"的场所**（机场、车站、码头）；功能＝把"说不出口的话"换成"跑得动的路"。换成别的剧种就没有这条规矩。

## 三、归因判据（★ 最硬的一条）

> **每个特征必须能归到六技术项之一，并写成一个"照做就能出来"的动作。归不了的，剔除。**

这条判据同时干三件事：把玩笑和特征分开、把结果和动作分开、把道德问题变成技术问题。

### 归不了的三种情况

**一、描述结果，不是描述动作。**

- ✗ "女性角色的脸都是同一个模子"——描述的是长相这个**结果**，不是任何一个可执行的动作。删掉。
- ✓ 改归到**美术·造型规范**："同一类型的女性角色共用一套妆造参数：眉形、眼型、发型弧度、唇色锁定在同一区间，差异只靠服装色阶区分。" 可参数化、可执行、可验真。

**注意：这不是礼貌问题，是技术问题。** "同一个模子"被淘汰不是因为它冒犯，是因为它归不到六项里、教不了任何人做任何事。换成上面的写法，它才第一次变成一条有用的知识。

**二、是设定，不是技术。**

- ✗ "韩剧男主都是财阀"——这是剧本设定。如果拆的是**视觉风格**，剔除；如果拆的是**类型片语法**，归到叙事结构，写成"第二幕必须给男主一个资源碾压的场景，用来把两人的关系从平等拉成不对等"。

**三、是偶然，不是规范。**

只在某一部作品出现过的，不是风格。要求代表作里重复 3 次以上。

## 四、归因演示

### 平地摔

| 技术项 | 参数 |
|---|---|
| 表演 | 失衡有固定顺序：重心先向前、双手来不及撑、膝盖先着地。**是一套编排，不是真的摔倒**——落点永远是安全的平面 |
| 剪辑 | 摔倒**前**必插一个脚部或地面特写，0.5–0.8 秒；摔倒动作本身反而不拍全，切点在身体接触地面之前 |
| 调度 | 落点必有人接住或撞见。**摔不是目的，被撞见才是**——这是它存在的理由 |

### 日剧跑

| 技术项 | 参数 |
|---|---|
| 运镜 | 侧前方约 45° 跟拍，焦距 35mm 上下，与被摄体保持 2–3 米，画面带轻微手持晃动 |
| 调度 | 前景必须有遮挡物（栏杆、行人、树枝）间歇掠过，制造速度感与被追赶感 |
| 声音 | 脚步声与呼吸声被明显放大，环境声压到几乎消失 |
| 剪辑 | 跑的过程切 3–5 个不同机位的短镜，每个 1.5–2.5 秒；不拍完整路程，只拍段落 |

### 日剧"诶"

| 技术项 | 参数 |
|---|---|
| 表演 | 反应延迟约 0.5 拍——先有一个吸气，再出声。不是即时应答 |
| 剪辑 | 反应镜头必留满约 1 秒，不提前切走 |
| 声音 | 短促的惊讶气声，混响很干，几乎没有空间感 |

### 韩剧绝症段

| 技术项 | 参数 |
|---|---|
| 叙事 | 落在第二幕尾（约第九集），因为前十集已用尽其他让两人对话的理由 |
| 美术 | 病房永远是暖白，绝不用冷调荧光——冷调会让观众联想到医疗，暖白联想的是家 |
| 光位 | 逆光让角色发丝透亮，脸的正面留一半在暗部 |
| 表演 | 症状只通过"停顿"与"按住某处"表现，不做痛苦表情。表情越克制，观众越难受 |

## 五、取样表的写法

一列特征，一列技术项，一列参数。写完自查：

1. 每条都有技术项吗？没有的删掉或改写。
2. 六项是不是都覆盖了？通常运镜与光位最容易漏，表演最容易被写成情绪词。
3. 参数能直接开工吗？"温柔的光""细腻的表演"一律不合格。
