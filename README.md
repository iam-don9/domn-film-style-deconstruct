## 怎么做（工作流）

<p align="center">
  <img src="./assets/readme/workflow.svg" width="100%" alt="domn-film-style-deconstruct 工作流：定风格→取样→归因→参数化→验真→写文案分镜">
</p>

> 换名即消失的才是风格；笑点只落套路不落人

1. **定风格** — 切到可识别、可取样的小范围
2. **取样** — ≥3 独立源只记共同条目，8–15 条
3. **归因** — 每条归到镜语六项/叙事一项，归不了剔除
4. **参数化** — 写可执行参数（“3200K 侧逆光左后45°”而非“温柔的光”）
5. **验真** — 比对 3 部代表作，对不上回炉
6. **写文案分镜** — 冷面吐槽体，口播逐段落镜
