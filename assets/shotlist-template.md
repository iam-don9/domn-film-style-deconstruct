# 分镜表 · 《标题》

**这是口播文案与生视频提示词之间的桥。** 文案是按"套路"写的，提示词是按"镜"生成的，中间必须有这张表把口播一行一行接到画面上。

**硬要求：口播每一段都要落到镜**——开场、各条套路、**本质揭示、元评论、收口**，一段都不能空。后三段最容易被漏，因为它们不是"套路"，但它们同样要播出去。

## 一、镜表

`镜型`：复刻镜（照参数拍出那个味）／演示镜（把参数怎么摆拍进画面）／对比镜（同镜两遍，只差一个参数）。

| # | 时间码 | 口播（对应行） | 画面 | 画面里的荒诞 | 镜型 | 本镜要验的参数 |
|---|---|---|---|---|---|---|
| 1 | 0.0–8.0 | | | | 复刻 | |
| 2 | | | | | | |
| 3 | | | | | | |

**时间码与生视频提示词的【6.分段计划】必须逐镜一致。**

**「画面里的荒诞」这一列不能空。** 复刻镜不只是演示参数，**还要承接口播的笑点**——口播里最荒诞的那一句，画面必须拍出来。

- 口播说"警察跑，坏蛋也跑"，画面就不能只拍一个人跑；要**四个人在同一画面里一起跑**。
- 口播说"所有人都跪下叫她女王"，画面里就得**真的有一排人跪下**。
- 画面还可以**比口播多给一笔**：口播说"坚决不搭车"，画面给一辆空车驶过、**没人看它**。

**自查**：把这句口播念出来，再看这一镜——画面里有没有它说的那个荒诞？没有，这一镜就是白拍的。

### 三段容易漏的，怎么给画面

- **本质揭示**——它本来就是对前面内容的复述，**不另拍新镜**：把各条套路的复刻镜各截 1.0 秒快闪重剪，配参数字幕卡。
- **元评论**——给**该风格的空镜**（如日剧＝傍晚电车、便利店灯光、雨后街道）。旁白在说观众的行为，画面保持安静，落差本身就是笑点。
- **收口**——给**全片最后一个画面**。最好回到开场那一镜的机位（闭环），或停在最标志性的那条套路上。
