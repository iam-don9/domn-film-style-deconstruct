# 生视频提示词模板

**每条参数一段**，每段 5–15 秒。三套骨架：A 复刻镜 / B 演示镜 / C 对比镜。
`[方括号]` 为待填内容。写法细则见 `references/06-tutorial-visual.md`。

七段职责（固定）：

| 段 | 职责 |
|---|---|
| 【1.全局设定】 | 第一句锁死实拍质感，再写风格质感锚点、实体道具、光影、镜头痕迹 |
| 【2.素材绑定】 | 每张图只干一件事：`@图片N 只定义 X，不得继承 Y` |
| 【3.画面契约】 | 本段要验的参数串 ＋ 主体特征串 ＋ 同框上限 |
| 【4.执行契约】 | 速度、剪点、机位、运镜、句法主动权、音频；对比镜加单一变量契约 |
| 【5.场景】 | 地点 ＋ 唯一光源 ＋ 空场状态 |
| 【6.分段计划】 | 段是叙事单位不是镜头单位；每镜写因果链，`末：`给可承接终态 |
| 【7.负向约束】 | 编号列"不要……"，最多 5 条 |

---

## A. 复刻镜（照参数拍出那个味）

```text
【1.全局设定】
真实电影摄影机实拍的画面，[该风格典型的光比与色温]，[手持／固定／肩扛]，[景深]。
被复刻的风格是 [风格名]，质感锚点是 [1–2 个最显眼的质感特征，如"青绿色偏、高光溢出、中间调颗粒"]。
主体是真人不是特效：[人物设定]。
[唯一光源的方向、高度、色温]，斜射到 [具体照到哪个面]；[背光面如何补亮]，不出现第二盏灯。

【2.素材绑定】
@图片1 只定义 [人物] 的长相与体型。不得继承：白底、棚拍光、正面证件站姿、图上标注。
@图片2 只定义 [服装与造型规范]。不得继承：白底平铺、分格拼贴、包装盒、第二视角。

【3.画面契约】
本段要验的参数串：[参数名]＝[具体取值]，全段不变。
人物特征串：[一次性写全]。
同框上限：画内人不超过 [N] 个。
材质连续：[衣摆／发丝／道具] 不受动作起止约束，主体停下后仍各自动半拍。

【4.执行契约】
速度契约：段内 [N] 镜、[N-1] 切点，单镜最长 [X] 秒。
[剪点契约：切点选在 [动作] 之前／之后，不拍完整动作。]
摄影：机位 [角度与焦距]，与被摄体距离 [X] 米。
运镜：[跟／推／固定]，运镜只由走位驱动。
句法主动权：[主体] 一律作主语写主动句。
音频：<[画面里真实能听见的声音]>。不要 bgm，不要字幕。

【5.场景】
[该风格典型的场景]，[时间]。唯一光源是 [方向与高度] 的 [光源]。空场状态：[无第二人、无标牌等]。

【6.分段计划】
段是叙事单位不是镜头单位，段内多切。
段 [X] [参数名] [起]–[止]，段内 [N] 镜：
镜1 [起]–[止] [取景]。[动作因果链]。
末：[给下一段的可承接终态]。

【7.负向约束】
1. 不要卡通渲染、游戏引擎质感或塑料玩具感。
2. 不要出现第二个人／[多余的物体]。
3. 不要破坏本段验的参数：[反向约束，如"不要把 45° 跟拍改成正面平拍"]。
4. 不要叠加字幕条、标题卡、参数卡、水印。
5. 不要 bgm、不要解说、不要字幕。
```

## B. 演示镜（展示参数怎么摆）

前五段同 A，只改这两段：

```text
【4.执行契约】
演示契约：画面内必须能看到 [摄影机机身一角／灯具边缘／前景遮挡物的位置]，让观众看清本段验的参数是怎么摆出来的；被摄体的表演保持中性，不抢焦点。
速度契约：段内 [N] 镜、[N-1] 切点，单镜最长 [X] 秒。
摄影：主机位 [角度]，画面内同时容纳 [被摄体] 与 [器材位置]。
句法主动权：[器材] 与 [被摄体] 各自作主语写主动句。
音频：<[现场声音]>。不要 bgm，不要字幕。

【6.分段计划】
段 [X] 演示·[参数名] [起]–[止]，段内 [N] 镜：
镜1 [起]–[止] [取景]。[器材] 摆在 [位置]，[被摄体] 在 [位置]，两者关系清晰可见。
末：[器材] 保持不动，[被摄体] 做一次 [动作]，画面停在两者关系上。
```

## C. 对比镜（同一镜两遍，只差一个参数）

```text
【4.执行契约】
对比契约：本段两镜必须同机位时长、同动作起止、同剪辑点，唯一变量是 [参数名]。除该变量外，两镜的景别、光位、表演、服化道完全一致，不得有任何第二个差异。
速度契约：段内 2 镜、1 切点，两镜时长必须相等，各 [X] 秒。
镜1（无）：[参数] 取 [对照值，如"正面平拍 50mm"]。
镜2（有）：[参数] 取 [本风格值，如"侧前方 45° 跟拍 35mm"]。
摄影：两镜除 [参数] 外，机位高度、光位、焦距外的所有设置不变。
运镜：运镜只由走位驱动，两镜的走位完全一致。
句法主动权：[主体] 一律作主语写主动句，两镜句式相同。
音频：两镜音效一致，<[声音]>。不要 bgm，不要字幕。

【6.分段计划】
段 [X] 对比·[参数名] [起]–[止]，段内 2 镜：
镜1 [起]–[止] 无该参数。[动作]，时长 [X] 秒。
镜2 [止]–[止+X] 有该参数。**完全相同的动作、完全相同的时长**，只有 [参数] 不同。
末：镜2 停在动作结束的同一帧位置上，与镜1 形成可逐帧对比的终态。

【7.负向约束】
1. 不要卡通渲染、游戏引擎质感或塑料玩具感。
2. 两镜之间不得出现第三个变量（光位、表演、服装、时长、剪辑点都必须一致）。
3. 两镜时长必须相等。
4. 不要叠加字幕条、标题卡、参数卡、水印。
5. 不要 bgm、不要解说、不要字幕。
```

---

## 填写时的三条硬要求

1. **参数必须写在【3.画面契约】的参数串里，且全段不变。** 参数是这段存在的理由，不能含糊。
2. **对比镜的单一变量是死线。** 出现第二个差异，这条对比就废了——观众看不出是哪个参数在起作用。
3. **所有文字卡（参数值、技术项标签、对比标识）留给后期叠加**，不写进提示词。
